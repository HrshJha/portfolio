# Design Decisions — Golden Hour

## 2026-08-17

- Kept the existing content and section order: hero, work, experience, about, toolkit, education, contact.
- Made light mode the default presentation so the atmospheric sky field is visible immediately; the existing theme toggle still supports dark mode.
- Locked the palette to warm dawn peach/gold, powder blue, ice white, and near-black technical surfaces. These are inspired by the supplied Sarvam reference, not copied brand assets.
- Added one low-opacity aperture construction behind the hero to connect the portfolio to photography without introducing decorative artwork.
- Added a monochrome toolkit marquee directly below the hero. Tool names remain muted so they do not compete with the atmospheric field.
- Kept Experience, Contact, and the footer near-black so visual intensity decays as information density increases.
- Preserved real project names, descriptions, experience entries, links, and contact details.
